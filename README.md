# The Plane of Focus

Interactive 3D camera lens optical bench laboratory built with React, TypeScript, Vite, and Three.js.

## Features

- Cutaway 3D cinema lens assembly with machined brass helical gears, multi-coated spherical glass elements, and a 12-blade articulated iris diaphragm.
- Real-time paraxial ray tracing and wavefront visualization showing exact convergence on the ground-glass plane.
- Interactive focus distance controls (`Foreground 36 cm`, `Middle 54 cm`, `Background 86 cm`, continuous slider, direct 3D ring drag, and keyboard shortcuts `1`, `2`, `3`).
- Physical depth-of-field (`Sharp Zone`) and circle-of-confusion telemetry across `f/2`, `f/5.6`, and `f/16`.
- Toggleable `Assembled` and `Exploded` mechanical inspection states with 3D leader-line component callouts.
